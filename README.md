## Модель прогнозирования задержки в доставке

```
Цель - построить модель бинарной классификации, которая на основе входных данных о заказе и профиле клиента 
предскажет вероятность задержки доставки.
```

### Постановка задачи

- **Тип задачи:** бинарная классификация
- **Метрики:** ROC-AUC, Precision, Recall
- **Целевой показатель:** ROC-AUC ≥ 0.75 на тестовой выборке
- **Целевая переменная:** `late_delivery_risk`

### Датасет
Исходные данные представлены двумя файлами:
1. `ds_s18_customers.csv`  - профили уникальных клиентов;
2. `ds_s18_orders.csv` - заказы клиентов;

### Модели

В рамках проекта проведено сравнение следующих алгоритмов:

1. `LogisticRegression` - базовая линейная модель;
2. `CatBoost` - модель градиентного бустинга.

Для оценки качеств использовалась метрика ROC-AUC. Дополнительно анализировались Precision и Recall 
с учетом бизнес-порога классификации. Разделение данных выполнено с группировкой по клиентам, чтобы исключить
попадание заказов одного клиента в разные выборки.

### Кластеризация

Для обогащения признакового пространства проведена сегментация клиентов с помощью алгоритма `KMeans` по двум направлениям:

* **Географическая кластеризация** — выделено 4 географические группы клиентов на основе координат. Качество разделения дополнительно
оценено силуэтным коэффициентом, который составил 0,759.
* **Поведенческая кластеризация** — выделено 5 сегментов на основе признаков `recency`, `total_orders`, `total_sales`, 
`return_rate` и `avg_discount`. Силуэтный коэффициент составил 0,416.

Полученные метки кластеров (`geo_cluster` и `beh_cluster`) добавлены в набор признаков для последующего обучения моделей.
Это позволило проверить гипотезу о влиянии географического положения и покупательского поведения клиентов на риск задержки доставки.

### Отбор и анализ признаков

Для повышения качества классификации и оценки вклада отдельных характеристик проведены:

* анализ корреляций между признаками;
* исследование важности признаков с помощью CatBoost;
* оценка влияния новых кластеризационных признаков.

Наиболее значимыми признаками итоговой модели оказались режим доставки (`shipping_mode`) и час оформления заказа (`order_hour`). 
Географическая и поведенческая сегментация внесли дополнительный, но сравнительно небольшой вклад в предсказания.

### Итоговые результаты

В качестве лучшей финальной модели выбран CatBoost с добавлением географических и поведенческих кластеризационных признаков.

| Метрика                       | ROC-AUC Valid |
|-------------------------------|:-------------:|
| CatBoost (cluster)            |     0.804     |
| CatBoost (base)               |     0.803     |
| Logistic Regression (cluster) |     0.742     |
| Logistic Regression (base)    |     0.737     |

Итоговый ROC-AUC на тестовой выборке составил `0,803`, что превышает установленный целевой порог 0,75.

При установленном бизнес-пороге классификации 0,7 модель показала:
* Precision = 0,87;
* Recall = 0,553.

Таким образом, модель демонстрирует достаточно высокую точность выявления потенциально задержанных заказов, 
однако обнаруживает около 55% всех фактических задержек.
Разработанная модель может использоваться для предварительной оценки риска задержки доставки, 
приоритизации контроля заказов и своевременного информирования клиентов о возможных задержках.
